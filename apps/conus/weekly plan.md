# CONUS ZERO

## 90-Day Weekly Action Plan

### The 90-Day Objective

CONUS Zero is not about launching everything.

It is about proving that the CONUS system can repeatedly create this behavior:

**Discover → Watch → Participate → Compete → Share → Return → Recognize → Create Opportunity → Attract Sponsors**

By Day 90, we should know what people actually respond to, what creators want, what communities rally around, what sponsors will pay for, and what parts of the system deserve to be built further.

---

# PHASE 1 — BUILD THE FOUNDATION

## Weeks 1–4

---

## WEEK 1 — Define the CONUS Zero System

### Objective

Turn the CONUS vision into a concrete first-season operating system.

### Actions

**Product**

* Define the exact CONUS Zero user journey.
* Define the minimum screens:

  * Home
  * Today's CONUS
  * Content/Topic
  * Challenge/Quiz
  * Results
  * Leaderboard
  * Profile
  * Creator/Founder profiles
  * Rewards
* Define what requires login.
* Define what can be viewed without login.
* Define participation rules.
* Define points, ranking and recognition logic.

**Content**

* Finalize the first 30 Daily CONUS topics.
* Define the CONUS Short format.
* Select the first short-form story/series concept.
* Define the first CONUS Challenge.
* Define the first CONUS Founders competition.

**Brand**

* Finalize CONUS language and positioning.
* Define the visual identity for Zero.
* Create the initial property architecture:

  * Daily CONUS
  * CONUS Short
  * CONUS Founders
  * CONUS Pitch
  * CONUS Challenge
  * CONUS Live
  * CONUS Fan
  * CONUS Local

**Business**

* Define founding sponsor proposition.
* Define initial sponsor categories.
* Identify 20–30 potential businesses/brands.

**Operations**

* Assign owners for product, content, growth, revenue and operations.
* Create the weekly CONUS operating meeting.

### Outputs

By Friday, you should have:

* CONUS Zero product map
* First-season content map
* Brand/property architecture
* Initial rules
* Initial reward model
* Sponsor proposition
* Team responsibilities
* 90-day production calendar

### Decision Gate

**Can everyone on the team explain what CONUS Zero actually is in one minute?**

If not, don't move forward.

# THE DAY-90 DECISION

Every CONUS property goes into one of three buckets.

## KEEP

It demonstrated meaningful behavior.

Keep investing.

## IMPROVE

The idea has potential, but the execution or format needs work.

Run another experiment.

## KILL

People consistently ignored it, the economics don't work, or it creates operational complexity without enough value.

Stop it.

* voting

### FRIDAY — COMPETE

* leaderboard
* rankings

### SATURDAY — RECOGNIZE

Then Monday starts again.

# THE MOST IMPORTANT RULE

Do not measure the first 90 days by how much software, content, branding or infrastructure gets produced.

Measure it by **behavior**.

The question every week is:

> **Did CONUS cause something to happen that would not have happened otherwise?**

Did someone discover someone?

Did someone watch?

Did someone participate?

Did someone return?

Did someone share?

Did someone compete?

Did someone become recognized?

Did someone get an opportunity?

Did a creator find an audience?

Did a community rally?

Did a business decide to fund the experience?

If the answer keeps becoming **yes**, CONUS Zero is working.
